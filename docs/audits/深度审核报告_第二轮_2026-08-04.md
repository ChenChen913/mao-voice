## 2. 新发现问题

### Major（1 项，建议立即修）

**N-M1. `_poll_recording` 对 `self.recorder` 存在 TOCTOU，异常将永久杀死自动停止轮询**

`main.py:259`：

```python
with self._lock:
    recording = self.state == "RECORDING"
if recording and self.recorder is not None and self.recorder.active:
```

锁内只读了 `recording`，锁外对 `self.recorder` 做**两次独立读取**（`is not None` 与 `.active`）。hotkey worker 的 `_start_recording` 失败路径会锁内置 `self.recorder = None`——若恰好落在两次读取之间，`None.active` 抛 AttributeError。该异常**不在任何 try 内**，逃出 Tk after 回调后，函数末尾的 `root.after(300, self._poll_recording)` 不再执行 → **静音自动停止 + max_duration 轮询永久静默失效**，v5.16 的 M4 修复随之形同虚设。

同文件 `_poll_level`（197-199 行）已在锁内取局部 `recorder`，两种写法并存，属修复不完整。

**修复（一行级）**：锁内 `recorder = self.recorder`，锁外全程用局部变量，与 `_poll_level` 对齐。
