## 1. 背景与定位

**一句话**：一款"说人话、出好文"的 Windows 桌面语音输入法——按住快捷键说话，松开即得经过**保守纠错、去语气词、智能标点**的干净文本，自动注入当前输入框。

**核心价值主张**：
1. **识别准**：本地 faster-whisper（GPU 加速）保证基础转写质量，断网可用；
2. **输出净**：大模型后处理自动过滤"嗯、啊、那个、然后"等语气词，自动加标点断句；
3. **微调克制**：默认只修明显识别错误（谐音、术语音译、标点），语义零改动，防止过度润色；
4. **越用越像你**：内置词库（术语/人名映射）让专属名词识别更准（完整自学习引擎为 post-MVP）。

**与竞品的差异**：不同于豆包/千问"语音输入 + AI 全家桶"，本项目主打"**保守纠错 + 开放可配置 + 本地优先**"，强调 AI 不擅自改写用户的话。

## 3. 目标用户与核心场景

- **目标用户**：需要大量文字输入的办公/内容创作者（写文档、记笔记、聊天长消息）。
- **核心场景（MVP 主场景）**：用户口述一段内容（30 秒~3 分钟），系统输出经过语气词过滤、标点补全、明显错误纠正的书面文本，并直接落入光标处。
- **演示场景（现场）**：
  1. 在记事本/聊天框里按住快捷键，口述一段带语气词、中英混杂的话；
  2. 松开后看到"转写 → 润色 → 注入"的完整过程；
  3. 输出文字干净、标点正确，术语（如 Python、JSON、GitHub）未被音译。

## 4. 功能需求

### P0（MVP 必须，演示闭环）

| 编号 | 需求 | 说明 | 验收标准 |
| --- | --- | --- | --- |
| F1 | 全局按住说话 | 按住快捷键开始录音，松开停止并进入处理 | 任意应用内可触发，无焦点限制 |
| F2 | 本地录音 | 16kHz 单声道 PCM 采集 | 录音文件/内存数据完整 |
| F3 | 本地转写 | faster-whisper（GPU 优先）转写为中文文本 | 松开后 3 秒内出粗转写（medium 模型） |
| F4 | LLM 保守纠错 | DeepSeek 后处理：去语气词、加标点断句、修谐音/术语 | 输出无语气词、标点正确、"配森"→"Python" |
| F5 | 文本注入 | 剪贴板 + 模拟 Ctrl+V 注入当前输入框 | 文字出现在当前光标处 |
| F6 | 悬浮窗状态反馈 | 录音中（实时草稿）→ 转写中 → 润色中 → 结果预览 | 用户全程可感知进度 |
| F7 | 词库 | `词库.txt` 维护术语映射，润色时强制遵守 | 词库内词条不被改写成其他形式 |
| F8 | 配置 | `config.json`：API Key、Base URL、模型、热键、润色强度 | 修改后重启生效 |

## 5. 非目标（Non-Goals）

1. 不训练/微调任何 ASR 或 LLM 模型；
2. 不做传统输入法形态（无候选栏、无皮肤、无拼音引擎）；
3. 不做账号体系、云同步、多设备；
4. 不做流式逐字转写引擎（草稿为增量块转写，最终以整段为准）；
5. 不承诺高于商业云 ASR 的识别准确率（卖点是输出质量与克制微调）。

## 6. 用户流程

```
按住快捷键 (右Ctrl)
   ↓
悬浮窗出现：录音中 + 实时草稿（每 ~2s 增量转写一次）
   ↓
松开快捷键
   ↓
悬浮窗：转写中…（整段完整转写）
   ↓
悬浮窗：润色中…（DeepSeek 后处理，遵守词库与强度档位）
   ↓
悬浮窗：结果预览（1.5s）
   ↓
自动注入：剪贴板 + Ctrl+V → 当前光标处
   ↓
悬浮窗隐藏，回到待机
```

**异常路径**：
- 未检测到 API Key → 跳过润色，直接注入粗转写并提示；
- 注入失败 → 文本保留在剪贴板，悬浮窗提示"已复制，请手动粘贴"；
- 录音过短（<0.5s）→ 忽略本次输入。

---

## 7. 交互与视觉要求

- **悬浮窗**：无边框、置顶、深色半透明胶囊（tkinter `overrideredirect` + `topmost`），显示于屏幕底部中央；
- **状态文案**：`🎤 录音中…` / `✍️ 转写中…` / `✨ 润色中…` / 结果预览；音量电平条（可选）；
- **全局热键**：默认 `右 Ctrl`（按住说话），`config.json` 可改（支持普通字母/功能键）；
- **运行形态**：后台常驻 + 悬浮窗，不显示主窗口（提供托盘图标为 P1）。

---

## 8. 数据与隐私

- 音频**仅在本地处理**（faster-whisper），不上传；
- 转写文本发送至 DeepSeek API 用于润色（用户可关闭润色，见 F8）；
- 词库与配置均为本地文件（`词库.txt`、`config.json`）；
- 不收集任何使用统计。

---

## 9. 验收标准（Demo 清单）

1. 在记事本中按住右 Ctrl 口述：`今天天气不错我想去公园走走然后买一杯咖啡还有我的 Python 项目配森也要改一下嗯就这样`；
2. 松开后 5 秒内，记事本出现：`今天天气不错，我想去公园走走，然后买一杯咖啡，还有我的 Python 项目（Python）也要改一下，就这样。`
   （语气词"嗯"被过滤，"配森"被纠正为"Python"，标点正确）
3. 词库测试：词库中加入 `喵酱=喵酱` 等专名，口述时不被改写；
4. 全程悬浮窗状态流转清晰可感知；
5. 断网状态下（关闭润色）仍能完成本地转写与注入。

## 附录：术语

- **ASR**：自动语音识别（Automatic Speech Recognition）。
- **粗转写**：ASR 直接输出的文本，含语气词与识别错误。
- **保守纠错**：只修复明显错误、不改写正确内容的 LLM 后处理原则。
- **词库**：用户维护的"必须按指定写法输出"的术语映射表。
